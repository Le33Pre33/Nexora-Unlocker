# Nexora Unlocker

Программа для Windows 10/11: находит процессы, которые держат файл или папку, и позволяет выполнить
с ними пакетные операции, даже если они заняты. Интерфейс в стиле Windows 11 (Fluent), светлая и тёмная темы.

## Возможности

- Поиск процессов, блокирующих файлы и папки (Windows Restart Manager), завершение выбранных процессов.
- Добавление файлов и папок кнопками или перетаскиванием в окно, пакетная обработка выбранных.
- Удаление в Корзину и безвозвратное удаление, перемещение, копирование.
- Переименование и массовое переименование по шаблону с предпросмотром и проверкой конфликтов.
- Удаление при перезагрузке (для того, что нельзя удалить сейчас).
- Прогресс, отмена, журнал операций.
- Защита системных путей и критичных процессов (включена по умолчанию, отключается в настройках).
- Сворачиваемые панели процессов и журнала, компактные настройки: тема, набор значков, защита.

### Шаблон переименования

| Переменная | Значение |
|---|---|
| `{имя}` | прежнее имя без расширения |
| `{номер}` / `{номер:3}` | счётчик с 1 / счётчик с нулями (`007`) |
| `{расш}` | расширение без точки |

Если в шаблоне нет точки и `{расш}`, расширение сохраняется автоматически: `Фото_{номер:3}` даст `Фото_001.jpg`.

## Установка (для пользователей)

Скачайте со страницы **Releases**:

- `NexoraUnlocker-Setup-<версия>.exe` — установщик: выбор папки, ярлык на рабочем столе, пункт в меню «Пуск»,
  удаление через «Параметры → Приложения → Установленные приложения».
- `NexoraUnlocker-Portable-<версия>.zip` — переносная версия: распакуйте и запустите `nexora-unlocker.exe`.
  Файл `portable.flag` рядом с программой хранит настройки в той же папке.

Ничего устанавливать дополнительно не нужно: Rust, Python и Visual C++ Redistributable не требуются
(исполняемый файл собран со статической библиотекой C).

Права администратора запрашиваются только по кнопке «Перезапустить от имени администратора» в настройках.
Они нужны, чтобы видеть и завершать процессы других пользователей и системные.

> Windows SmartScreen может показать предупреждение: файл не подписан цифровой подписью (она платная).
> Нажмите «Подробнее → Выполнить в любом случае» только если скачали файл из своего репозитория или официального релиза.

## Сборка (для разработчиков)

Нужны: Windows 10/11, Rust (stable), Visual Studio Build Tools с компонентом «Разработка классических приложений на C++»,
для установщика ещё Inno Setup 6.

```bat
install-deps.bat --installer   :: проверит и (с вашего согласия) установит недостающее через winget
build.bat                      :: cargo build --release  -> target\release\nexora-unlocker.exe
package.bat                    :: dist\NexoraUnlocker-Setup-<версия>.exe и dist\NexoraUnlocker-Portable-<версия>.zip
package.bat --portable-only    :: только ZIP, без Inno Setup
cargo test                     :: тесты
```

Скрипты работают с пробелами и кириллицей в путях и возвращают код ошибки при сбое.
В VS Code: `Ctrl+Shift+B` запускает сборку (см. `.vscode/tasks.json`).

После первой сборки закоммитьте `Cargo.lock` (для приложений он хранится в репозитории).

## Публикация на GitHub и релизы

1. Создайте репозиторий и загрузите проект (папка `target` и `dist` игнорируются `.gitignore`).
2. Каждый push и pull request собирается и проверяется в GitHub Actions (`.github/workflows/release.yml`).
3. Чтобы выпустить версию: поднимите `version` в `Cargo.toml`, затем

   ```bat
   git tag v0.3.0
   git push origin v0.3.0
   ```

   Workflow соберёт установщик и ZIP и приложит их к релизу автоматически.

## Структура

```
src/main.rs      точка входа и окно
src/ui.rs        интерфейс, панели, фоновые задачи
src/fsops.rs     файловые операции, шаблоны переименования, защита путей (с тестами)
src/sys.rs       Windows API: блокирующие процессы, завершение, права администратора
src/settings.rs  настройки (тема, значки, панели), файл settings.ini
assets/          иконка и манифест
installer/       скрипт Inno Setup
```

Настройки: `%APPDATA%\NexoraUnlocker\settings.ini` (в переносной версии рядом с программой).
Состояние защиты системных путей не сохраняется: после перезапуска она всегда включена.

## Безопасность

- Защищены каталоги Windows, Program Files, ProgramData, корни дисков, корень профиля пользователя,
  Корзина и System Volume Information; критичные процессы (системные, службы, проводник) не завершаются.
- Опасные операции (безвозвратное удаление, завершение процессов, отключение защиты, действия над
  системными путями при выключенной защите) требуют подтверждения.
- Программа не обходит UAC, не отключает Windows Defender и не трогает чужие защитные механизмы.
- Завершение процесса приводит к потере его несохранённых данных.

## Известные ограничения

- Интерфейс только на русском.
- Файлы под защитой TrustedInstaller и ядро Windows программа не разблокирует.
- Если Restart Manager не смог проверить элемент, статус будет «Не проверено», а не «Свободен».
- Лицензия в проекте не указана: выберите её сами перед публикацией.
